22:T3c5d,<h2 id="what-this-game-is">What this game is</h2>
<p>Supermarket Chaos is puzzle game about stocking shelves. Pick item, find shelf, get $0.10. Then game throw thousands of products on floor.</p>
<p>Game has <strong>three Modes</strong>. You unlock next after you clear current one. My hub follow same order:</p>

<p>Same core loop all three stages. Skills and stickers carry over. <a href="/supermarket-chaos/achievement-hunting">Achievement milestones per stage</a>.</p>
<p>Leaf pages: <strong>Stage 2</strong> shelf counts + <strong>Stage 3</strong> SuperSupermarket bays (below).</p>

<h2 id="core-loop-all-stages">Core loop (all stages)</h2>
<ol>
<li>Pick up product from floor</li>
<li>Find shelf — white tag = right shelf but not full, yellow = done, <strong>red = wrong shelf</strong> (does not count)</li>
<li>Place → $0.10</li>
<li>Mouse wheel switch held items, right-click throw (need Dunk Shot skill for auto-stock)</li>
</ol>
<p>Rule: <strong>red tags never count</strong> toward completion. Move item immediately.</p>
<p><img src="https://pub-569323f832f84244a5766b065936dc37.r2.dev/LucasGuide/Supermarket-Chaos-Right-Click-Throw-LucasGuide.jpg" alt="Right-click throw — stock from distance with Dunk Shot"></p>

<h2 id="request-more-method-all-stages">Request More method (all stages)</h2>
<p>After you unlock Request More:</p>
<ol>
<li>Pick <strong>one</strong> product from category you want to clear</li>
<li>Press <strong>4</strong> — all matching items teleport to you</li>
<li>Stock them on correct shelf</li>
<li>Repeat until category done → <strong>star reward</strong> (Stage 1) or section clear (Stage 2/3)</li>
</ol>
<p>I use this in all three Modes. Stage 3 is mostly same method, just much more volume.</p>
<hr>
<h2 id="stage-1-supermarket-4667-items">Stage 1 — Supermarket (4,667 items)</h2>
<p>First Mode — <strong>Supermarket</strong>. Big grocery store — toiletries, produce, frozen, wine aisle. This is where you learn loop and buy skills.</p>
<p><img src="https://pub-569323f832f84244a5766b065936dc37.r2.dev/LucasGuide/Supermarket-Chaos-Stage-1-Start-LucasGuide.jpg" alt="Stage 1 — Supermarket start"></p>
<p><strong>Stage clear:</strong> correctly place all <strong>4,667</strong> items (UI sometimes round to 4,600 — same thing, every item on right shelf). Walk to exit → <strong>Employee of the Month</strong>.</p>
<h3>Ending (Stage 1)</h3>
<p>This happen <strong>only in Mode 1</strong> when Supermarket is fully stocked. Exit screen show <strong>Employee of the Month</strong> and your <strong>clear time</strong> — game save how long Mode 1 took you. Good for comparing runs or bragging to friends.</p>
<p>Then robot <strong>GPT-9000</strong> pop up and tell you that you <strong>messed up its plan</strong>. Store was supposed to stay chaos; you put everything back anyway. Story hook for Mode 2 — not the final credits of whole game.</p>
<p><img src="https://pub-569323f832f84244a5766b065936dc37.r2.dev/LucasGuide/Supermarket-Chaos-Ending-LucasGuide.jpg" alt="Stage 1 ending — clear time and GPT-9000"></p>
<h3>My category order (Stage 1)</h3>
<p>Small sections first, less backtracking:</p>
<ol>
<li><strong>Toiletries</strong> — shampoo, bath tissue, toothpaste</li>
<li><strong>Canned goods</strong> — red beans</li>
<li><strong>Produce</strong> — avocado → grapefruit → kiwi → banana → apple → mango → papaya → carrot</li>
<li><strong>Tea</strong> — small tea boxes</li>
<li><strong>Lemon cake</strong> shelf</li>
<li><strong>Dairy + meat</strong> — yogurt, buttermilk, eggs, cheese; <strong>ground beef is separate cooler</strong></li>
<li><strong>Frozen / dry</strong> — chicken wings, ramen packs</li>
<li><strong>Beverages</strong> — cola and juices first, then wine (Nocturn, Kasa Martino, Tennessee Whiskey, Bordeaux House Cabernet, Chateau Lunair, etc.)</li>
<li><strong>Final sweep</strong> — crouch under tables (CTRL), <strong>Reposition all</strong> if needed</li>
</ol>
<p>Last missing items usually under produce table or red-tag wrong shelf.</p>
<h3>Stage 1 — stickers start here</h3>
<p>Stars from finishing product categories → gacha / ATM near produce. Worth doing before Stage 2: <a href="/supermarket-chaos/sticker-collection">sticker collection</a>.</p>
<p><img src="https://pub-569323f832f84244a5766b065936dc37.r2.dev/LucasGuide/Supermarket-Chaos-ATM-gacha-LucasGuide.jpg" alt="Gacha machine and ATMs — near fruit and vegetable section"></p>
<p>When Stage 1 done, game unlock <strong>Dreamlike Convenience Store</strong>.</p>
<hr>
<h2 id="stage-2-dreamlike-convenience-store-2628-items">Stage 2 — Dreamlike Convenience Store (2,628 items)</h2>
<p>Second Mode — <strong>Dreamlike Convenience Store</strong>. Different layout — <strong>every SKU needs exact shelf sections</strong> (mostly 2 sections per product). Mistake one count = section not complete.</p>
<p><strong>Stage clear:</strong> <strong>2,628</strong> correct placements → <strong>Second Store Complete</strong> achievement. Watch <strong>2,627 vs 2,628</strong> — Really One More achievement is one placement before finish.</p>
<h3>Stage 2 only — change sky</h3>
<p><strong>My Own Sky</strong> achievement: change sky <strong>3 times</strong> (computer / panel in this stage). Easy to miss if you rush clear.</p>
<h3>My category order (Stage 2)</h3>
<p>Entrance → back:</p>
<ol>
<li><a href="/supermarket-chaos/magazine-shelf-placement">Magazines</a> — 16 titles, start here</li>
<li><a href="/supermarket-chaos/electronics-tools-shelf-placement">Electronics &#x26; tools</a></li>
<li><a href="/supermarket-chaos/snacks-cereal-shelf-placement">Snacks &#x26; cereal</a> — crisps need 4 sections</li>
<li><a href="/supermarket-chaos/ramen-shelf-placement">Ramen</a> — must finish before cleaning</li>
<li><a href="/supermarket-chaos/cleaning-laundry-shelf-placement">Cleaning &#x26; laundry</a></li>
<li><a href="/supermarket-chaos/hair-care-shelf-placement">Hair care</a></li>
<li><strong>Drinks, canned alcohol, frozen, bento</strong> — same 2-section rule; counts on tooltip when you pick item up</li>
</ol>

<p>When Stage 2 done, game unlock <strong>SuperSupermarket</strong> (Stage 3). Achievements call it <strong>Mega Market</strong>.</p>

<h2 id="stage-3-supersupermarket-mega-market-9999-placements">Stage 3 — SuperSupermarket / Mega Market (9,999 placements)</h2>
<p>Third Mode — <strong>SuperSupermarket</strong> in game, <strong>Mega Market</strong> in achievement names. Huge store split into <strong>18 bays</strong> (Drinks → Albums/LPs). Same stocking rules: correct shelf, even split per table.</p>
<p><strong>Honest note:</strong> I <strong>not finish</strong> Stage 3 solo yet. This Mode is too big for one evening after work. Bay numbers in <a href="/supermarket-chaos/supersupermarket-shelf-placement">SuperSupermarket shelf guide</a> come from community list + my partial runs — I verify more when I play, but for now I <strong>recommend co-op with friends</strong>.</p>
<h3>Multiplayer (Beta) — how I suggest you play Stage 3</h3>
<p>Game add <strong>multiplayer (Beta)</strong>. Official rules:</p>
<ul>
<li><strong>2–4 players</strong> can play together — depends on Mode</li>
<li>Costumes available — cosmetic, but fun</li>
<li><strong>Progress saves only on host save file</strong> — if you not host, your file not advance; host must run the session</li>
</ul>
<p>What this mean for you:</p>
<ol>
<li><strong>Host</strong> = person whose supermarket / stage progress matter. Pick friend with most skills unlocked or who is closest to Stage 3.</li>
<li>Split bays — one player Drinks + Beer, another Meat + Bread, etc. Request More still OP with four people hauling.</li>
<li>Guest players help place items but <strong>milestones and bay clear count toward host</strong> — do not expect your save to move if you join someone else lobby.</li>
<li>Beta = maybe bugs. If count look wrong, retry session or host solo for that bay.</li>
</ol>
<p>I will update this hub when I clear more bays solo or in co-op myself.</p>
<p><strong>Two things at once in Stage 3:</strong></p>
<ol>
<li><strong>Clear each bay</strong> — exact totals in <a href="/supermarket-chaos/supersupermarket-shelf-placement">SuperSupermarket shelf guide</a> (all 18 bays)</li>
<li><strong>Placement milestones</strong> — counter to <strong>9,999</strong> correct for Mega Market Complete</li>
</ol>
<h3>My bay order (Stage 3)</h3>
<p>Follow Bay <strong>1 → 18</strong> in shelf guide. Request More on big lines (Bay 1 drinks, Bay 7 fish, Bay 8 cheese, Bay 12 ramen).</p>
<p>Special rules in this Mode:</p>
<ul>
<li><strong>Bay 13 &#x26; 17</strong> — most items use <strong>1 shelf</strong> only</li>
<li><strong>Bay 14 shoes</strong> — every SKU is 8 units, 2 shelves, 4 each</li>
<li><strong>Bay 10 snacks</strong> — names look like Dreamlike store but <strong>different counts</strong> — use Stage 3 table only</li>
</ul>
<h3>Stage 3 tips</h3>
<ul>
<li><strong>Seriously Too Heavy</strong> achievement: hold <strong>20 items</strong> at once — need max Extra Carry</li>
<li>At <strong>9,990+</strong> open achievement list — <strong>One Last Item, Really</strong> = 9,998, <strong>Mega Market Complete</strong> = 9,999</li>
<li>Distance achievements (Marathoner 42.195 km) fill passively while you walk</li>
<li>Stickers (-30% cooldown, +30% duration) help long grind: <a href="/supermarket-chaos/sticker-collection">sticker collection</a></li>
</ul>
<p>Full milestone table: <a href="/supermarket-chaos/achievement-hunting">achievement hunting</a>.</p>
