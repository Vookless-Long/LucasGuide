## Prologue — London

Notebook + torch, read desk papers, Kensington study safe.

1. Opening cutscene → take **notebook**, **torch**. Revolver on desk — leave it.
2. Read documents in study.
3. Safe in private study — code from papers (March 31, 1909).

![Prologue safe code 033109](https://pub-569323f832f84244a5766b065936dc37.r2.dev/LucasGuide/TES-001-Puzzle-033109-LucasGuide.jpg)

4. Graves cutscene → ticket for Southampton.

## Chapter 1 — Southampton

No puzzles — boarding + cabin.

1. Present ticket, walk gangway.
2. Follow steward **Thomas** to cabin **C70**.

![Cabin C70](https://pub-569323f832f84244a5766b065936dc37.r2.dev/LucasGuide/TES-002-Cable-C70-LucasGuide.jpg)

3. Read note — meet Sinclair smoke room 6:00 p.m.
4. Sleep in bed → chapter end.

## Chapter 2 — A-Deck

1. Grand Staircase lounge → **Edward Sinclair** — protect **Book of Thoth**, rival **Rothvil**.
2. F-Deck cargo hold → inspect crate **404** (seal intact).

![Cargo crate 404](https://pub-569323f832f84244a5766b065936dc37.r2.dev/LucasGuide/TES-003-Crate-404-LucasGuide.jpg)

3. Lady Harrington in lounge.
4. Sinclair murder cutscene → autosave. Can't return to cargo after.

## Chapter 3 — Investigation

1. Report death to **captain** → unrestricted deck access.
2. Lady Harrington — show **cipher** from Sinclair's body.
3. Learn **Mr. Pumble** (Rothvil's accountant) can read code.
4. Objective: Turkish baths F Deck.

## Chapter 4 — Turkish Baths

Ventilation = locked-room murder method. Hard part = [steam barricade](/titanic-escape-simulator/steam-room-barricade-puzzle).

1. Promenade — **Isidor Strauss** (steward sighting).
2. Sinclair's suite — **Thomas Andrews**, symbols on Sinclair's hand = ventilation map (baths → suite grates).
3. Second Class Restaurant — **Guggenheim** (cooling room).
4. Confront **Pumble** — Graves link.
5. Turkish baths — suspect barricaded hot room → **steam controls** (leaf guide).
6. Guggenheim bribe offer — refuse or accept, story unchanged.
7. Report to captain.

## Chapter 5 — Brig to Boiler Room Six

1. Wake in brig → lockpicks at feet → pick cell door.
2. Notebook outside cell.
3. Master-at-Arms office — **Wild dead**, code **0404** on paper.

![Master-at-Arms code 0404](https://pub-569323f832f84244a5766b065936dc37.r2.dev/LucasGuide/TES-004-Puzzle-0404-LucasGuide.jpg)

4. Use **0404** on armory / secure door.
5. Schedule: Graves locks wireless room **23:30**.
6. Wireless room — warn **Jack Phillips**, keep him on duty.

![Wireless room](https://pub-569323f832f84244a5766b065936dc37.r2.dev/LucasGuide/TES-005-Wireless-Room-LucasGuide.jpg)

7. **Boiler Room Six** — [Graves fight](/titanic-escape-simulator/confrontation-with-graves-in-boiler-room-six).

## Chapters 6–7 — Sinking

Linear escape after iceberg. Move fast in cold water.

1. Swim flooded lower decks.
2. **Bolt cutters** on chains (from Graves room if you grabbed them).
3. Break glass / vents where marked.
4. **Axe** on security gates.
5. Climb shifting catwalks.
6. **Revolver** on catwalk chain — drops path upward.
7. **Boat Deck** → [three endings](/titanic-escape-simulator/final-ending-choices).

![Boat Deck finale](https://pub-569323f832f84244a5766b065936dc37.r2.dev/LucasGuide/TES-006-Boat-Deck-LucasGuide.jpg)
