11 trophies, all story. No collectibles, no speedrun gates.

| Achievement | Unlock |
| --- | --- |
| MY STORY | Finish prologue |
| THE ARRIVAL | Level 1 |
| THE GILDED CAGE | Level 2 |
| THE SHADOWS & DUST | Level 3 |
| THE ALIBI | Level 4 |
| THE CULT OF THOTH | Level 5 |
| THE COLD FREQUENCY | Level 6 |
| THE SINKING | Level 7 |
| THE EXECUTIONER | [Ending 1](/titanic-escape-simulator/final-ending-choices) — shoot Rothvil |
| THE THIEVES IN THE NIGHT | Ending 2 — save Eliza |
| THE GREATER GOOD | Ending 3 — cut lifeboat ropes |

First eight = impossible to miss if you finish the game.

## 100% route

1. Play through normally → MY STORY through THE SINKING.
2. Manual save on Boat Deck.
3. Ending 1 → reload → Ending 2 → reload → Ending 3.

One extra session if you save before the choice. Blind play = up to three runs.
