## What this game is

Supermarket Chaos is puzzle game about stocking shelves. Pick item, find shelf, get $0.10. Then game throw thousands of products on floor.

Game has **three Modes**. You unlock next after you clear current one. My hub follow same order:

| Stage | Mode | Items (correct placements) | Goal |
| --- | --- | --- | --- |
| **1** | Supermarket | **4,667** | Employee of the Month — first big store |
| **2** | Dreamlike Convenience Store | **2,628** | Second Store Complete — strict shelf sections |
| **3** | SuperSupermarket (Mega Market) | **18 bays** + **9,999** placement counter | Mega Market Complete |

Same core loop all three stages. Skills and stickers carry over. [Achievement milestones per stage](/supermarket-chaos/achievement-hunting).

Leaf pages: **Stage 2** shelf counts + **Stage 3** SuperSupermarket bays (below).

## Core loop (all stages)

1. Pick up product from floor  
2. Find shelf — white tag = right shelf but not full, yellow = done, **red = wrong shelf** (does not count)  
3. Place → $0.10  
4. Mouse wheel switch held items, right-click throw (need Dunk Shot skill for auto-stock)  

Rule: **red tags never count** toward completion. Move item immediately.

![Right-click throw — stock from distance with Dunk Shot](https://pub-569323f832f84244a5766b065936dc37.r2.dev/LucasGuide/Supermarket-Chaos-Right-Click-Throw-LucasGuide.jpg)

## Skill upgrade order

Open skills: **ESC → lightbulb icon**. I upgrade these in **Stage 1** and use same build in Stage 2 and 3.

| Priority | Skill | Why |
| --- | --- | --- |
| 1 | Extra Carry | 5 → 15 items (later 18). Less walking. |
| 2 | Request More (key 4) | Teleport all matching products to you. Best skill in game. |
| 3 | Matchfinder (key 2) | Highlight same products. Auto-pick with Matchfinder+. |
| 4 | Shelf Finder (key 1) | Shows shelf for held item. |
| 5 | Dunk Shot + Throw Boost | Throw stock from distance. |
| 6 | Quick Step + Sprint | Move faster. |

Do not buy cosmetic stuff early. Skills first — Stage 3 grind is long without them.

![Skill menu — ESC, lightbulb icon](https://pub-569323f832f84244a5766b065936dc37.r2.dev/LucasGuide/Supermarket-Chaos-Skills-LucasGuide.jpg)

## Request More method (all stages)

After you unlock Request More:

1. Pick **one** product from category you want to clear  
2. Press **4** — all matching items teleport to you  
3. Stock them on correct shelf  
4. Repeat until category done → **star reward** (Stage 1) or section clear (Stage 2/3)  

I use this in all three Modes. Stage 3 is mostly same method, just much more volume.

## Stage 1 — Supermarket (4,667 items)

First Mode — **Supermarket**. Big grocery store — toiletries, produce, frozen, wine aisle. This is where you learn loop and buy skills.

![Stage 1 — Supermarket start](https://pub-569323f832f84244a5766b065936dc37.r2.dev/LucasGuide/Supermarket-Chaos-Stage-1-Start-LucasGuide.jpg)

**Stage clear:** correctly place all **4,667** items (UI sometimes round to 4,600 — same thing, every item on right shelf). Walk to exit → **Employee of the Month**.

### Ending (Stage 1)

This happen **only in Mode 1** when Supermarket is fully stocked. Exit screen show **Employee of the Month** and your **clear time** — game save how long Mode 1 took you. Good for comparing runs or bragging to friends.

Then robot **GPT-9000** pop up and tell you that you **messed up its plan**. Store was supposed to stay chaos; you put everything back anyway. Story hook for Mode 2 — not the final credits of whole game.

![Stage 1 ending — clear time and GPT-9000](https://pub-569323f832f84244a5766b065936dc37.r2.dev/LucasGuide/Supermarket-Chaos-Ending-LucasGuide.jpg)

### My category order (Stage 1)

Small sections first, less backtracking:

1. **Toiletries** — shampoo, bath tissue, toothpaste  
2. **Canned goods** — red beans  
3. **Produce** — avocado → grapefruit → kiwi → banana → apple → mango → papaya → carrot  
4. **Tea** — small tea boxes  
5. **Lemon cake** shelf  
6. **Dairy + meat** — yogurt, buttermilk, eggs, cheese; **ground beef is separate cooler**  
7. **Frozen / dry** — chicken wings, ramen packs  
8. **Beverages** — cola and juices first, then wine (Nocturn, Kasa Martino, Tennessee Whiskey, Bordeaux House Cabernet, Chateau Lunair, etc.)  
9. **Final sweep** — crouch under tables (CTRL), **Reposition all** if needed  

Last missing items usually under produce table or red-tag wrong shelf.

### Stage 1 — stickers start here

Stars from finishing product categories → gacha / ATM near produce. Worth doing before Stage 2: [sticker collection](/supermarket-chaos/sticker-collection).

![Gacha machine and ATMs — near fruit and vegetable section](https://pub-569323f832f84244a5766b065936dc37.r2.dev/LucasGuide/Supermarket-Chaos-ATM-gacha-LucasGuide.jpg)

When Stage 1 done, game unlock **Dreamlike Convenience Store**.

## Stage 2 — Dreamlike Convenience Store (2,628 items)

Second Mode — **Dreamlike Convenience Store**. Different layout — **every SKU needs exact shelf sections** (mostly 2 sections per product). Mistake one count = section not complete.

**Stage clear:** **2,628** correct placements → **Second Store Complete** achievement. Watch **2,627 vs 2,628** — Really One More achievement is one placement before finish.

### Stage 2 only — change sky

**My Own Sky** achievement: change sky **3 times** (computer / panel in this stage). Easy to miss if you rush clear.

### My category order (Stage 2)

Entrance → back:

1. [Magazines](/supermarket-chaos/magazine-shelf-placement) — 16 titles, start here  
2. [Electronics & tools](/supermarket-chaos/electronics-tools-shelf-placement)  
3. [Snacks & cereal](/supermarket-chaos/snacks-cereal-shelf-placement) — crisps need 4 sections  
4. [Ramen](/supermarket-chaos/ramen-shelf-placement) — must finish before cleaning  
5. [Cleaning & laundry](/supermarket-chaos/cleaning-laundry-shelf-placement)  
6. [Hair care](/supermarket-chaos/hair-care-shelf-placement)  
7. **Drinks, canned alcohol, frozen, bento** — same 2-section rule; counts on tooltip when you pick item up

## Stage 3 — SuperSupermarket / Mega Market (9,999 placements)

Third Mode — **SuperSupermarket** in game, **Mega Market** in achievement names. Huge store split into **18 bays** (Drinks → Albums/LPs). Same stocking rules: correct shelf, even split per table.

**Honest note:** I **not finish** Stage 3 solo yet. This Mode is too big for one evening after work. Bay numbers in [SuperSupermarket shelf guide](/supermarket-chaos/supersupermarket-shelf-placement) come from community list + my partial runs — I verify more when I play, but for now I **recommend co-op with friends**.

### Multiplayer (Beta) — how I suggest you play Stage 3

Game add **multiplayer (Beta)**. Official rules:

- **2–4 players** can play together — depends on Mode  
- Costumes available — cosmetic, but fun  
- **Progress saves only on host save file** — if you not host, your file not advance; host must run the session  

What this mean for you:

1. **Host** = person whose supermarket / stage progress matter. Pick friend with most skills unlocked or who is closest to Stage 3.  
2. Split bays — one player Drinks + Beer, another Meat + Bread, etc. Request More still OP with four people hauling.  
3. Guest players help place items but **milestones and bay clear count toward host** — do not expect your save to move if you join someone else lobby.  
4. Beta = maybe bugs. If count look wrong, retry session or host solo for that bay.

I will update this hub when I clear more bays solo or in co-op myself.

**Two things at once in Stage 3:**

1. **Clear each bay** — exact totals in [SuperSupermarket shelf guide](/supermarket-chaos/supersupermarket-shelf-placement) (all 18 bays)  
2. **Placement milestones** — counter to **9,999** correct for Mega Market Complete  

### My bay order (Stage 3)

Follow Bay **1 → 18** in shelf guide. Request More on big lines (Bay 1 drinks, Bay 7 fish, Bay 8 cheese, Bay 12 ramen).

Special rules in this Mode:

- **Bay 13 & 17** — most items use **1 shelf** only  
- **Bay 14 shoes** — every SKU is 8 units, 2 shelves, 4 each  
- **Bay 10 snacks** — names look like Dreamlike store but **different counts** — use Stage 3 table only  

### Stage 3 tips

- **Seriously Too Heavy** achievement: hold **20 items** at once — need max Extra Carry  
- At **9,990+** open achievement list — **One Last Item, Really** = 9,998, **Mega Market Complete** = 9,999  
- Distance achievements (Marathoner 42.195 km) fill passively while you walk  
- Stickers (-30% cooldown, +30% duration) help long grind: [sticker collection](/supermarket-chaos/sticker-collection)  

Full milestone table: [achievement hunting](/supermarket-chaos/achievement-hunting).

## Lost items fix (any stage)

1. **ESC** → green power button  
2. Scroll down → **Reposition all items not on shelves**  

I use this every time at 99% in Stage 1 or 2.

## Reset notes

**New game floor reset:** ESC → green tab → **Delete All** (irreversible).

**Steam achievement reset:** uninstall, disable cloud, delete `BunnyHopHome` in AppData, Steam console `reset_all_stats 4800590`. Only if you want full wipe.
