Stage 3 Mode in game is **SuperSupermarket**. Achievements call it **Mega Market** — same place.

**I not clear this Mode solo yet.** Too many bays for one person after job. Numbers below are reference for you and friends — split work in **multiplayer (Beta)** when you can.

### Multiplayer (Beta) — official + practical

From patch notes:

- **2–4 players** together (Mode-dependent)  
- Costumes — just for fun  
- **Multiplayer progress saves only to host save file**  

So: host the lobby if you want **your** Stage 3 / Mega Market achievements to move. Joining friend game helps them, not your save (unless you only care about hanging out — also valid).

Co-op tip: assign bays per player (Bay 1–4, 5–8, …) or split by row. One person runs Request More, others carry to shelf. Much faster than solo.

This is the shelf reference I use when we play. Rule is simple: **total units ÷ shelf count = per shelf**. Game want even split unless tooltip say otherwise.

**My bay order:** Bay 1 → 18 straight through. Request More still best for big stacks (drinks, ramen, cheese).

> **Note:** Bay 12 list two products named **Seafood Cup Noodles** — one 108 stack, one 8 stack. In game check label on small stack; may read Cup Ramen. Do not mix with big seafood cup line.
