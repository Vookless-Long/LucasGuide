# Treasure Map 3 from Alice

![Alice in the Elderfield Library](https://pub-569323f832f84244a5766b065936dc37.r2.dev/LucasGuide/Welcome-to-Elderfield-NPC-Alice-LucasGuide.jpg)

Treasure Map 3 is one of those collectibles that punishes players who treat the Library as a one-and-done story beat. Alice only hands it over if you actually stop and talk to her, and the map itself points somewhere most people sprint past on their first visit.

I run the Library loop on every fresh save, so this is the exact order I use to grab the map, read it, and cash in the treasure before I move on to the next objective.

| --- | --- | --- |
| 1 | Talk to Alice inside the Elderfield Library | Dialogue triggers |
| 2 | Accept the map when she offers it | **Treasure Map 3** added to inventory |
| 3 | Open the map and follow the marked location | Hidden treasure |

- **Prerequisite:** Talk to Alice in the Library — no other quest flag required.
- **Reward:** Treasure Map 3 (leads to a hidden treasure).
- **Chapter:** Elderfield Library.

### Talk to Alice in the Library First

Alice is the gate. Nothing else in this chain works until you walk up and start the conversation. If you have been treating the Library as pure set dressing while hunting the [energizing blast in welcome to elderfield](/welcome-to-elderfield/ritual-skills-reference) ritual, you have probably walked right past her.

Do this, not that:

1. Enter the Elderfield Library and clear the main reading floor.
2. Find Alice and talk to her — exhaust her dialogue, don't cut it short.
3. Accept Treasure Map 3 the moment she offers it.

> **Tip:** I always finish the Library's other pickups in the same visit. Since you are already standing in the room, grabbing the [energizing blast in welcome to elderfield](/welcome-to-elderfield/ritual-skills-reference) ritual costs you almost no extra time and saves a return trip later.

### Receive Treasure Map 3

Once Alice hands it over, the map lands in your inventory as a key item. It does not auto-solve anything — you still have to read it and physically travel to the marked spot.

- Confirm it is in your inventory before you leave the Library.
- Read the map's description text; the location hint is written there, not on your quest log.
- Do not sell or drop it. It is a quest item, not vendor trash.

> **Note:** If you are running a fresh save, this pairs naturally with the [welcome to elderfield foraging and resource collection](/welcome-to-elderfield/foraging-and-resource-collection) route, since the treasure path usually cuts through wilderness terrain where herbs and mushrooms spawn anyway.

### Follow the Map to the Treasure Location

This is where most players stall. The map does not put a glowing marker on your screen — you have to match the description to the terrain and walk it yourself.

My rule when I test this route:

1. Open the map and read the location description carefully.
2. Head to the matching area rather than wandering randomly.
3. Search the marked spot — the treasure is a physical object, not an auto-grant.
4. Loot it and confirm the reward popup before leaving.

> **Warning:** Do not trigger a world event mid-route. If a [blood moon event in welcome to elderfield](/welcome-to-elderfield/moon-events) fires while you are traveling, mysteries reset and monsters respawn — which can bury the treasure spot under fresh enemies. Finish the map run first, then deal with the moon.

### What You Get and Why It Matters

| Item | Source | Purpose |
| --- | --- | --- |
| Treasure Map 3 | Alice (Elderfield Library) | Points to a hidden treasure |
| Hidden treasure | Map-marked location | Loot reward |

Treasure Map 3 is a low-effort, high-return collectible. The only real cost is the detour, and the only real failure state is skipping Alice's dialogue entirely.

- **Sprinting past Alice.** If you never talk to her, the map never exists for you.
- **Ignoring the map text.** The location hint lives in the item description, not the quest tracker.
- **Leaving the Library empty-handed.** Grab the [energizing blast in welcome to elderfield](/welcome-to-elderfield/ritual-skills-reference) ritual while you are there.
- **Running the route during a world event.** A [strange moon event in welcome to elderfield](/welcome-to-elderfield/moon-events) stacks Dread on you for a full day, which is a bad time to be exploring for a hidden cache.

### My Route Order

When I optimize a Library visit, it looks like this:

1. Enter the Library and clear the floor.
2. Talk to Alice and take Treasure Map 3.
3. Grab the [energizing blast in welcome to elderfield](/welcome-to-elderfield/ritual-skills-reference) ritual on the way out.
4. Leave and follow the map to the treasure.
5. Loot, then resume normal progression.

That order keeps you from backtracking and keeps the map run clean.

### Final Thoughts

Treasure Map 3 is a clean example of why talking to every NPC matters in Welcome to Elderfield. Alice is not a decoration — she is a collectible dispenser, and the map she gives you is a free loot run if you actually read it. Grab it early, follow the description instead of guessing, and you will have the treasure in one trip instead of three.
