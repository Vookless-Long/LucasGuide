# Passcode Lock — Dave's House

**Daves Home**

Dave's house in the Residential Area hides one of the earliest hard gates in Welcome to Elderfield: a passcode lock that blocks progress until you feed it the right digits. The game gives you zero hints at the door itself, which is exactly why so many players stall here on their first run.

### Step 1: Get Into Dave's House

Before the lock even matters, you need access to the Residential Area and Dave's house specifically.

1. Reach the **Residential Area** — it's the neighborhood zone with the houses, not the wilderness or farm outskirts.

2. Find **Dave's house** among the residential buildings.
3. Enter the house. If the door won't open, you're missing a prerequisite from earlier in the Residential Area — solve that first, then come back.

If you're still early in the game and juggling multiple side objectives, it helps to knock out the low-friction collectibles first. I usually clear the [welcome to elderfield cooking and recipes](/welcome-to-elderfield/cooking-and-crafting) unlocks at my own house before heading into the Residential Area, because the fridge and inventory ingredients carry over and save me a return trip later.

### Step 2: Locate the Passcode Lock

Once you're inside Dave's house, the lock is the interaction point you're looking for.

1. Walk the interior of Dave's house — don't rush to the exit.
2. Look for the **passcode lock** interaction prompt. It's a distinct object, not a standard door.
3. Note its position relative to the rest of the room. This matters because the code is usually tied to something nearby.

> **Warning:** Don't leave Dave's house after finding the lock without checking the rest of the interior. If you walk out, you'll likely have to re-enter and re-sweep — pure wasted time.

### Step 3: Find the Passcode

The code is the part of this puzzle that isn't handed to you. Based on how Elderfield structures its other gates, the passcode is discovered through the environment rather than a menu.

Here's how I approach any unknown code in this game:

1. **Sweep the room the lock is in.** Read every note, poster, or readable object. Codes in Elderfield are frequently written somewhere visible but easy to skip.
2. **Check adjacent rooms in the same building.** If Dave's house has multiple rooms, the code may be in a different one than the lock.
3. **Look for number sequences on objects.** Clocks, calendars, signs, and labeled items are common code carriers.
4. **Re-read anything you already interacted with.** A note you skimmed on the way in is the most common miss.

> **Tip:** When I test code puzzles, I screenshot every readable object the moment I see it. It costs nothing and eliminates the backtracking loop that eats 10+ minutes per attempt.

### Step 4: Enter the Code and Open the Lock

Once you have the digits:

1. Interact with the **passcode lock**.
2. Enter the code exactly as found — order and digit count matter.
3. Confirm. The lock opens and the path behind it is now accessible.

If the code is rejected, do not assume the code is wrong. Check these three things in order:

| Check | Why It Fails | Fix |
| --- | --- | --- |
| Digit order | You read it backwards or out of sequence | Re-read the source object left-to-right, top-to-bottom |
| Digit count | You dropped or added a number | Count the digits on the source, then count your input |
| Wrong code source | You used a code from a different lock | Confirm the source object is inside Dave's house |

> **Note:** Elderfield reuses the passcode-lock interaction type in multiple locations. If you've solved a different lock earlier, don't assume the same code carries over — each lock has its own value.

- **Brute-forcing the lock.** The game doesn't reward guessing. Find the code.
- **Leaving the house to "look for the code elsewhere."** The code is tied to Dave's house. Search inward, not outward.
- **Skipping readable objects.** The single most common reason players get stuck here is walking past a note without reading it.
- **Assuming the lock is optional.** If it's blocking your route, treat it as mandatory and solve it now rather than later.
